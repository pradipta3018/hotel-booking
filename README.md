# 📊 Data Analytics & Power BI Dashboard Project

## Overview

GrandStay Hotels, a leading chain of luxury accommodations, seeks to optimise its operations and enhance guest experiences through data-driven decision-making. A centralised dashboard will provide actionable insights into booking trends, revenue generation, guest demographics, and operational efficiency.

This project demonstrates an end-to-end **data analytics workflow**, from importing and preparing raw data to developing an interactive Power BI dashboard and presenting actionable insights.

The project focuses on **Exploratory Data Analysis (EDA), Data Cleaning, Data Modelling, DAX, Data Visualisation, and Reporting**. A final presentation was also created using Gamma to communicate the key findings.

## Project Workflow

### 1. Data Loading
- Imported the dataset into a spreadsheet.
- Reviewed column names, data types, and overall structure.
- Identified potential data quality issues.

### 2. Exploratory Data Analysis (EDA)
- Explored data distributions and key variables.
- Identified missing values, duplicates, and outliers.
- Analysed trends, patterns, and relationships.

### 3. Data Cleaning & Transformation
- Handled missing and inconsistent values.
- Removed duplicate records where appropriate.
- Standardised column names and data formats.
- Prepared the dataset for reporting and visualisation.

### 4. Data Modelling & DAX
- Loaded the cleaned data into Power BI.
- Created relationships between tables where required.
- Implemented DAX measures and calculated columns.
- Developed KPIs to support analytical insights.

### 5. Power BI Dashboard
- Designed an interactive dashboard.
- Created KPI cards, charts, and tables.
- Added slicers and filters for dynamic exploration.
- Applied clear and consistent visual design principles.

### 6. Reporting & Presentation
- Prepared a report summarising the analysis and findings.
- Highlighted key insights and recommendations.
- Created a professional project presentation using **Gamma**.

## How to Run the Project

1. **Clone or download** this GitHub repository.
2. Open the dataset in Microsoft Excel to review the source data.
3. Open the `.pbix` file using Power BI Desktop.
4. Update the dataset source path if required.
5. Refresh the data to load the latest records.
6. Explore the dashboard using slicers, filters, and interactive visuals.
7. Review the project report and Gamma presentation for detailed findings.
